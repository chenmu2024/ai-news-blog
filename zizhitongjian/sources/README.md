# 原典检索入口

## 1. 第一底本：四部丛刊本

维基文库：
https://zh.wikisource.org/zh-hant/資治通鑑_(四部叢刊本)

用途：全文定位、按卷阅读、上下文核验。自动 Gate 优先使用具体卷的 `zh-hant` 页面，以避免简繁自动转换造成逐字校验误判。

维基文库另有《资治通鉴目录》，可辅助按时代定位：
https://zh.wikisource.org/zh-hant/資治通鑑目錄

## 2. 第二底本：四库全书影印本

Chinese Text Project 总入口：
https://ctext.org/wiki.pl?if=gb&res=593436

用途：查找对应卷的具体页面，并通过其与底本影像关联的图文对照复核重要原句。每篇文章必须记录具体卷 URL（含 `chapter=`），不能只保存总入口。

## 3. 检索纪律

- 先人物/事件定位，再回卷次；
- 至少阅读目标段落前后完整上下文；
- 不能用搜索结果摘要代替原文；
- 重要原句至少完成一次第二底本影印复核；
- 若两个版本出现异文，在内部来源记录中注明，不擅自挑选更“好看”的版本；
- 二手文章只允许做线索，不允许做原典证据。
