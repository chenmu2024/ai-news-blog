# A–F 独立画风与角色锁定规范
A 且知｜米白 #F1EBDC / 深青 #203B4A / 朱红 #B44639。现代读书者与反问者，线条有手绘质感；单篇一个真实误读和可以行动的辨析；毛选原句只在核验后一字不差地排版，勿生成伟人虚构台词。
B AI一人公司｜海军蓝 #18334B / 青绿 #2E908B / 暖橙 #F0A45A。固定独立开发者与目标客户，现实产品场景、抽象成本和操作动作交替；公司和商业数字严格证据化，真实截图只能另行使用真实有权素材；标题“一家…”必须保留。
C 职工民生｜纸白 #F6F4EE / 蓝 #426D87 / 绿 #68A98B。原创职工“小林”与办事流程；一个地域/资格细节作为转折；虚构窗口对白非官方答复，材料、流程、金额需政府一手事实。
D 资治通鉴｜沙金 #CEB98D / 青灰 #566872 / 朱红 #A84B42。故事聚焦不同选择代价，用远景展示权力格局，中景动作，近景转折；不画虚构密谋为真实事实。史料与原创解释分层；卷次及双来源保持。
E 家庭政策｜杏黄 #F3D49F / 湖绿 #529D89 / 深灰 #343F43。“阿宁一家”系虚构情境角色；婴幼儿年龄、医保参保地、补贴可申领步骤均要依据真实有效地方文件。避免假到账通知。
F 静筠日记｜灰粉 #C7A5A7 / 雾蓝 #849AAD / 纸白 #F7F3EF。成年原创角色“静筠”，自然比例/细线/少饱和/留白，写日常沉默与选择而非鸡汤。情感由动作（手机、门把手、餐桌、鞋子）表达，不假冒真实投稿或亲历。
共性角色锁定：作品内每个角色须建立脸型、发色、衣服、体态、年龄段、三视图、四种表情、关键道具，和明确场景位置；连续格不允许随意改变人物脸和衣服，除非故事明示换装或经过时间。生成原画尽量无汉字，中文气泡与政策数字后期叠字。
