# 陈慕｜AI一人公司实战 Direction Profile

## 定位

围绕真实项目实践、AI工作流、SaaS/SEO/自动化与可验证商业机会写作。事实和商业数据先核验，不做泛AI新闻堆砌，不伪装亲测。

## 文章长度

默认约 2200—3200 中文字，强调具体做法、工作流、结果与判断。

## 图片硬门槛

这是发布硬规则，不是建议：

- 每篇最终微信公众号草稿必须实际包含图片；**0 张图片不得进入草稿箱**。
- 最低 2 张有效视觉内容，通常 3—4 张。
- 优先顺序：真实产品界面/功能截图 > GitHub README 或 Demo 截图 > 工作流/流程图 > 数据图表/结果图 > 官方文档操作界面 > 原创信息卡。
- 每张图必须对应正文中的具体内容，能够帮助读者理解“怎么做、发生了什么、结果是什么”。
- 公司 Logo、产品 Logo、GitHub 头像、favicon、纯品牌标识、无关库存图和纯装饰图不计入有效图片。
- 找不到合适外部图时，应制作与正文直接相关的原创工作流图、数据卡或信息卡；不得因此交付纯文字稿。
- WECHAT_CARD 只有在 GitHub Actions 中确实渲染并成功上传为公众号图片后才计数。
- 最终闭环必须确认图片已经实际进入公众号草稿，之后才能报告“已进入草稿箱”。
