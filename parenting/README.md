# 陈慕｜育儿与家庭教育

主理人 / 作者：**陈慕**

定位：不贩卖育儿焦虑，讲清孩子行为背后的原因，也讲父母真正能怎么做。

## 目录

- `STYLE.md`：写作、来源、医疗边界、配图规范
- `archive/YYYY-MM-DD.md`：每日文章归档
- `articles/today.md`：最近一次成功草稿对应文章
- `status/quality-gate.json`：内容质量 Gate
- `status/latest.json`：草稿闭环状态
- `publish_draft.py`：微信公众号草稿桥

## GitHub Actions Secrets

- `PARENTING_WECHAT_APP_ID`
- `PARENTING_WECHAT_APP_SECRET`
- `PROXY_URL`（继续共用现有静态代理）

只创建草稿，不自动发布。
