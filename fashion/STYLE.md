# 女装穿搭｜Image-first Direction Profile

## 定位

内部 Direction：`fashion`

正式账号名暂不在系统里改写，等待沿用用户现有公众号名称。

核心定位：**明星穿搭 × 日韩穿搭 × 普通人复刻。**

不是时尚资讯搬运号，也不是“看图猜同款”。每篇文章必须先有合格图片和可追溯来源，才允许进入写作。

内容比例建议：
- **80% 明星穿搭**：以内地女明星、日韩女明星的机场、出街、剧宣、红毯外的日常造型和品牌活动为核心；按连续7篇至少5篇有明确明星本人真实照片执行。
- **15% 日韩明星风格的普通人复刻专题**：必须明确参考哪位明星、哪一组可核验公开造型，真实原图与复刻示意分清楚。
- **5% 季节性日韩普通穿搭**：作为明星造型补充，若近7篇明星比例不足则自动降级不写。

普通日系素人街拍、西装裙装泛教程不再是默认日更主线。2026-10-10既有成功归档属于旧方向样本，不能改动同日归档触发重复草稿。今后的备选题先列明确明星姓名与出处，不能没有人物资料就改写泛穿搭。

## 明星选题的硬要求（2026-10-10更新）

- 每日首选有较高公众知名度、最近14天有公开造型信号的明星；中国大陆明星优先兼顾日韩明星。没有近期事件时使用有日期的经典造型，明确不是当天新造型。
- 公众号标题优先出现**真实明星姓名 + 场景或强对比 + 普通人可以学的比例**，禁用抽象泛标题替代人物；原稿与微信公众号标题均≤32字。
- 80%是滚动7篇内容配额，非每一篇都强制明星；未完成5篇明星主线时不选择纯素人穿搭。
- 先查最近30天已写的明星，不得为了流量每天反复写同一人/同一组图；优先候选含杨幂、刘亦菲、赵露思、Jisoo、Jennie、张员瑛、宋慧乔、林允儿等，人物及其照片需逐次核验。
- 每篇至少5张真实**明星本人穿搭**照片且正文与相应图片一一对应。可从同一明星的多次造型中选5张，也可用至少3名明星的不同造型；不拿素人图、AI复刻图充当5张明星原图。
- 所有照片保留可核验的页面/摄影来源，优先品牌新闻稿、明星公开社交媒体、正规媒体图库。新闻配图有版权时遵守版权与转载约束；公开可见不等于天然授权。
- 单独解释哪些信息来源确认（人物、地点、活动、日期、品牌）及哪些只是穿搭观察，不虚构精确同款和身材数据。

## Image-first 硬流程

固定顺序：

**找图 → 记录来源 → 确认人物/场景 → 必要的单品事实核验 → 穿搭分析 → 普通人复刻 → Image Gate → Quality Gate → 微信草稿**

不得反过来先写文章再随便补图。

图片规则以真实明星、合法授权、相关性及可追溯为先。可以参考 Pexels、Unsplash、Pixabay、小红书、Instagram、Pinterest、品牌官网、明星公开社媒及新闻配图选题，但**只有确有微信公众号图文二次使用许可的真人照片才能正式采用**；保留来源页、权利人、授权类型与证据。公开可见不等于可转载。AI 图只能清楚标注为非真人示意，不能计入5张真人明星照片。

仍然禁止：
- AI 图冒充真实明星、真人街拍或新闻现场；
- 偷拍、明显私密、付费墙内、来源完全不明或水印严重的高风险图片；
- 看图猜品牌、型号、SKU 或精确价格；
- Logo、头像、无关图凑数量。

## 明星与日韩穿搭图片

优先具有适用许可的 Wikimedia Commons 明星真实照片、明确授予二次使用许可的新闻/品牌 press 素材或权利人书面授权照片；核验许可是否允许商业使用、是否要求署名、是否限制改编。仅能查看、没有可验证转载许可的品牌、社媒、新闻图不得计入五张真人图。

AI 图可用于普通人复刻、比例、配色、层次、单品组合与封面示意，但必须明确作为示意内容使用，不得暗示为真实明星本人或真实活动照片。

## 单品与“同款”规则

严禁只靠视觉猜品牌、型号、价格。

只有来源能明确证明时才可以写：
- “同款”
- “她穿的是 XXX”
- 精确品牌 / 型号 / SKU / 价格

无法确认时必须改写成：
- “同类版型”
- “类似的短款针织”
- “可以找这种肩线/裤型/配色”
- “这套最值得抄的是比例，不是具体品牌”

## 每篇固定分析维度

不要求机械全部出现，但至少覆盖 5 项：
- 廓形：肩、腰、衣长、裤型、裙摆；
- 比例：上短下长 / 上宽下直 / 内紧外松等；
- 配色：主色、对比度、明度、冷暖；
- 材质：软硬、垂坠、厚薄、光泽；
- 层次：叠穿、露肤、领口、袖口；
- 鞋包：体积、颜色、风格平衡；
- 身材适配：小个子、高个子、肩宽、胯宽等；
- 季节与场景：通勤、约会、旅行、日常；
- 普通人复刻：哪些必须抄，哪些不必抄。

## 普通人复刻

每篇都必须回答：

1. **这套真正值得抄的是什么？**
2. **普通人应该搜什么类型的单品？**
3. **哪些身材需要调整比例？**
4. **预算不够时先把钱花在哪里？**

默认不做“假同款”。

允许写：
- 500 元级搭配思路；
- 1500 元级搭配思路；
- 品类关键词；
- 平替版型逻辑。

涉及具体商品推荐时，商品事实必须从当日可核验页面确认，不凭记忆写价格和库存。

## 标题方向

推荐：
- 《这套机场穿搭真正好看的，不是那只包》
- 《韩国女生穿西装为什么不显“上班感”？关键在这3个比例》
- 《日本女生敢把裙子套裤子，为什么看起来不乱？》
- 《这套大衣看起来贵，真正起作用的是裤子》
- 《160cm照着这套穿，最应该改的不是鞋》
- 《别急着买同款，这套最值得抄的是“上宽下直”》

避免：
- “女明星都在穿”
- “今年不买就过时”
- “显瘦20斤”
- “所有女生都适合”
- 未核验就写“同款”“平替”“某某同款”。

## 文章长度与节奏

篇幅由实际材料决定，不设目标字数，不靠重复总结扩写；先读 content_os/PRODUCTION_BRIEF.md。

图片为核心证据，**每篇至少 5 张，通常 5–8 张**；质量和相关性优先，但不得少于 5 张。优先使用小红书、Instagram、Pinterest、品牌/明星公开社媒等真实穿搭图片，Pexels/Unsplash 只作补充。
文字围绕图片展开，不写与图无关的长篇时尚史。

推荐结构：
主图 → 第一眼判断 → 廓形/比例 → 配色/材质 → 细节 → 身材适配 → 普通人复刻 → 预算分配。

## 图片与隐私边界

禁止：
- AI 生成明星或真人穿搭图冒充真实照片；
- 偷拍、私密场景、未经许可的普通人照片；
- 儿童/未成年人穿搭作为成人时尚流量素材；
- 水印图库图片；
- 把不同造型的图拼在一起说成同一套；
- 用“相似图片”假装原造型。

## 前台 / 后台分离

后台必须保留：
- 图片 URL；
- 来源页 URL；
- 权利/许可类型；
- 权利证据 URL；
- 是否需要署名；
- 单品来源；
- 图片与正文对应关系。

公开正文不显示技术性核验过程。
如许可要求署名，只显示必要、自然、简短的图片署名，不写内部工作流。

## 发布

归档：`fashion/archive/YYYY-MM-DD.md`

图片核验：`fashion/image_gate.py`

每篇必须包含隐藏的 `FASHION_SOURCE` JSON。

只创建微信公众号草稿，不自动正式发布/群发。

## 图片硬门槛

这是发布硬规则：

- 每篇最终微信公众号草稿必须实际包含 **至少 5 张有效图片**，通常 5—8 张；少于 5 张不得进入草稿箱。优先从小红书、Instagram、Pinterest、品牌/明星公开社媒寻找真实穿搭图片，公共素材站只作补充。
- 图片必须实际出现在正文，并在 FASHION_SOURCE 留下可追溯的基本来源记录；缺少可验证的相应二次使用授权必须拒稿。
- 仍然禁止 AI 图冒充明星/真实街拍、来源完全不明的高风险图、明显私密或偷拍内容、Logo 或无关图凑数。
- Image Gate 与最终草稿闭环核对实际图片数量、来源记录与事实边界。


## 全局微信热门选题前置

每日选题前必须先读取并执行 `content_os/TOPIC_INTELLIGENCE.md`：先用免费公开来源扫描近期同类型微信公众号热门/高表现文章，再进行本方向选题、近30天去重和事实核验。禁止使用 TinyFish；未完成微信热门扫描不得直接进入正式选题。
