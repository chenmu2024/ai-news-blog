# 且知公众号写作规范

## 定位
“且知”主要写《毛泽东选集》中的方法论，把大历史拆成小日常，把大战略拆成普通人今天能理解、能执行的方法。

## 内容来源优先级
1. 项目内《毛泽东选集》第一至四卷电子书：作为原文、篇目、观点和引语的主要依据。
2. 项目内合订资料中的第五卷：需要时补充。
3. 六、七卷及其他民间整理材料：只能作为补充，使用时必须意识到版本性质不同，不把民间整理材料冒充第一至四卷官方版本。
4. 用户提供的6篇样文：作为写作风格、标题、结构、节奏、现代转译和配图形式的主要样本，不作为毛选原文真实性的替代来源。

## 风格必须贴近样文
- 标题优先使用“毛选 + 数字 + 现实问题/能力/方法”，但不能每篇机械重复。
- 开头三种形式轮换：现实痛点直入、反常识结论、历史故事。
- 不写成学术论文、读书笔记、新闻稿或AI报告。
- 正文通常拆成3—7个清晰模块。
- 每一条优先采用：毛选原文/原意 → 白话解释 → 历史或现实案例 → 今天怎么用 → 一个具体动作。
- 原文负责权威，解释负责传播；现代管理工具只能作为解释器，不能冒充毛泽东原话。
- 多用短句。每个模块尽量有一句能单独截图传播的话。
- 允许重新命名概念，如“决策铁三角”“条件聚合”“防线幻觉”，但名称必须建立在原文逻辑上，不能凭空发明结论。
- 适当穿插刘邦、项羽、韩信、韦睿等历史人物或现代创业、管理、职场场景，但案例必须服务观点。
- 结尾短，用一句话压缩全文，再留一个低门槛评论问题；可以使用A/B/C选择题。

## 文章长度
默认约1800—2800中文字符。主题需要时可略长，但不要为了字数灌水。

## 引文纪律
- 直接引号内的毛泽东原文必须先回到项目电子书核对。
- 能确定篇名时标注篇名，如“——《反对本本主义》”。
- 不能确定逐字原文时，不使用引号，改写为“这篇文章的意思是/可以概括为”。
- 不得把作者的现代概括、MVP、PDCA、二八法则等写成毛泽东原话。
- 不得编造篇名、年份、批注和历史细节。

## 配图
每篇4—6张AI图：
- 1张公众号封面图；
- 1张核心框架总图；
- 2—4张正文重点信息图/概念图。

统一视觉：
- 米白/宣纸感背景；
- 暗红 + 黯金为主色；
- 现代国风知识卡片；
- 留白多、层级清楚；
- 类似用户提供的“毛选五大战略思维”信息图；
- 中文文字尽量少而准，不堆小字；
- 不出现水印、无关Logo、政治宣传海报式构图。

## 图片标记格式
在Markdown中插入以下隐藏标记，发布脚本会自动调用AI生图并上传微信公众号：

封面：
<!-- QIEZHI_IMAGE role=cover :: 这里写完整AI生图提示词 -->

正文：
<!-- QIEZHI_IMAGE role=inline :: 这里写完整AI生图提示词 -->

封面标记不会出现在正文；inline标记会被替换成公众号正文图片。

## 禁止出现
最终正文绝对不要出现：来源核验说明、配图说明、生成说明、编辑说明、内部备注、AI提示词、Markdown/HTML技术说明、HTTP状态码、工作流说明等。
