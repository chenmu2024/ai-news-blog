# 原典检索入口

## 1. 第一底本：四部丛刊本

维基文库：
https://zh.wikisource.org/zh-hans/資治通鑑_(四部叢刊本)

用途：全文定位、按卷阅读、上下文核验。

维基文库另有《资治通鉴目录》，可辅助按时代定位：
https://zh.wikisource.org/zh-hans/資治通鑑目錄

## 2. 第二底本：四库全书影印本

Chinese Text Project：
https://ctext.org/library.pl?if=gb&res=7

用途：影印原页复核。资源说明为《钦定四库全书》本《资治通鉴》，294卷/141册，浙江大学图书馆藏本，CADAL扫描。

## 3. 检索纪律

- 先人物/事件定位，再回卷次；
- 至少阅读目标段落前后完整上下文；
- 不能用搜索结果摘要代替原文；
- 重要原句至少完成一次第二底本影印复核；
- 若两个版本出现异文，在内部来源记录中注明，不擅自挑选更“好看”的版本；
- 二手文章只允许做线索，不允许做原典证据。
