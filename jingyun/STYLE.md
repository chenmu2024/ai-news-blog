# 静筠日记｜女性生活 Direction Profile

## 定位

账号名：**静筠日记**

公开作者人格：**静筠**

一句话：**写女人真正经历的生活。**

副定位：**婚姻、家庭、工作、钱，以及那些到了某个年纪才慢慢明白的事。**

核心读者：30–50 岁女性。不是泛女性鸡汤号，不靠性别对立制造流量，也不把每篇文章都写成“离开他 / 爱自己 / 搞钱 / 拒绝内耗”。

这个号关注的是一个女人在真实生活里的处境、选择、代价和重新理解自己。

## 与其他账号区分

- 育儿号：中心问题是“孩子怎么了，父母能怎么做”。
- 静筠日记：中心问题是“一个女人在这件事里经历了什么，她真正面对的选择是什么”。

同一个题材也必须换中心视角。

例如：
- 育儿号：《孩子说“不想上学”，先别急着讲道理》
- 静筠日记：《孩子慢慢长大以后，很多妈妈才发现自己不知道为谁而活》

## 内容主线

- 25% 婚姻与长期关系：分工、冷淡、沟通、失望、边界、重新理解。
- 20% 中年女性：35+ / 40+ 后的身份、身体、工作、关系和生活重心变化。
- 15% 女性与钱：收入能力、家庭财务安全感、全职妈妈重返职场、离婚后的经济现实。
- 15% 工作与家庭：职业空窗、重返职场、照顾责任、选择与代价。
- 10% 母女与代际：母亲变老、原生家庭、理解与边界。
- 5% 成年女性友情：渐行渐远、重新选择关系、陪伴。
- 5% 离婚/重新选择：不鼓励、不污名化，重点写现实成本与判断。
- 5% 自我成长：边界、自尊、孤独、讨好、重新开始，但拒绝空泛鸡汤。

## 选题标准

优先写读者会产生“这就是我 / 我身边就有这样的事”的题。

每篇至少满足：
1. 一个具体生活场景或现实矛盾；
2. 有真实的现实成本，不把问题简化成一句态度；
3. 至少有一个值得讨论的选择，而不是预设唯一正确答案；
4. 与近 30 天文章不撞题；
5. 涉及事实、法律、职场、心理、健康、财务时按事实核验规则处理。

## 标题

推荐：
- 《40岁以后，我越来越不想证明自己了》
- 《中年夫妻最难熬的，往往不是没钱》
- 《孩子慢慢长大，我才发现最该重新安排的是自己的人生》
- 《妈妈老了以后，我才开始理解她当年的很多选择》
- 《一个女人真正需要的安全感，最后还是要有一部分握在自己手里》
- 《人到中年才发现，有些朋友真的只能陪你走一段》

避免：
- “男人都……”“女人一定要……”
- “远离消耗你的人”“狠狠爱自己”等批量鸡汤套话
- “99%的女人都错了”“聪明女人从不……”等标签化标题
- 用离婚、出轨、婆媳冲突做低质量猎奇
- 把复杂关系简单归结成“他不爱你了”

## 故事真实性规则

这是硬规则。

账号名叫“静筠日记”，但**静筠是稳定的编辑/作者声音，不是可以随意编造人生的虚构真人。**

未经真实来源支持，禁止写：
- “昨天我和老公吵了一架”
- “我女儿今年上初中”
- “我离婚那年……”
- “我有一个闺蜜……”
- “我做咨询时遇到一个来访者……”

如果不是作者真实发生过的事，不得用第一人称冒充亲历。

可以写：
- “一个女人到了40岁，常常会同时面对几件事……”
- “最近有一个讨论里，很多女性反复提到……”
- “有些家庭会出现这样的场景……”
- “一位公开受访者曾提到……”

如使用读者投稿、公开采访、新闻个案，必须有真实来源和必要匿名处理，不自行补写未公开细节。

## 文章结构

正文建议 1800–2800 中文字。

优先结构：
具体生活场景 → 她真正卡在哪里 → 外人最容易怎么理解 → 现实里有哪些选择 → 每个选择有什么代价 → 一个更诚实的判断 → 回到生活本身。

不要固定“五点建议”“三个道理”。

允许结论复杂：
- 婚姻不好，不代表离婚一定是最优答案；
- 全职妈妈想工作，也不能忽略孩子照护和职业空窗；
- “独立”不仅是态度，也包括收入、能力和支持系统；
- 有些关系不是谁坏，而是双方需求已经发生变化。

## 文风

像一个成熟、克制、见过复杂生活的女性作者。

需要：
- 有生活细节；
- 能理解女性处境，也能理解现实约束；
- 有判断，但不站在道德高地；
- 有情绪，但不煽动；
- 写“钱”时讲现实，不喊口号；
- 写婚姻时不自动站队；
- 写母女关系时允许爱与怨同时存在。

避免：
- 性别对立；
- 鸡汤式励志；
- 每篇都“你要爱自己”；
- 每篇都劝离婚；
- 每篇都劝搞钱；
- AI式总结；
- 一句一段的短视频口播腔；
- 把专业心理学术语随意套到普通关系问题上。

## 事实与专业边界

普通生活叙事不需要堆专家。

但出现以下内容时必须核验：
- 婚姻/离婚/财产/抚养等法律问题；
- 抑郁、焦虑、自伤、家暴等心理/安全问题；
- 女性健康、围绝经期、生育、睡眠等健康问题；
- 收入、就业、人口、婚育等统计数据；
- 金融投资、保险、债务等财务问题。

专业事实优先官方机构、法律法规、专业协会、医院/大学、高可信研究和正式媒体。

涉及家暴、胁迫控制、跟踪、威胁、人身安全时，不以“沟通技巧”代替安全建议；应优先提醒寻求当地紧急支持、可信任的人或专业机构。

## 配图

目标 3–5 张，**真实生活场景为主，信息卡只作补充。**

推荐：
- 2–3 张有明确使用许可的真实女性生活、家庭、工作、城市、中年生活场景图；
- 1–2 张时间线、关系图、数据卡或简洁文字卡；
- 涉及具体人物/新闻时优先官方或有明确许可的真实图片。

禁止：
- 用AI生成“中年女人哭泣”等图片冒充真实个案；
- 用受伤、哭泣、冲突等强刺激画面制造情绪；
- 用陌生女性私密或羞辱性照片；
- Logo、无关库存图凑数。

## 前台 / 后台分离

固定原则：**后台重核验，前台保持干净。**

公开正文不得出现：
- “资料来源 / 图片来源 / 核验说明 / 编辑说明 / 发布说明”
- 内部选题评分、事实核验过程、图片候选
- API / HTTP / Markdown / Content-Type 等技术信息

这些全部留在内部流程。

## 排版视觉规范

「静筠日记」固定使用克制、温暖的编辑杂志感，不做粉色少女风，也不做企业报告风。

视觉关键词：
- 暖白 / 米白背景感；
- 深灰棕正文；
- 低饱和豆沙色作为唯一主要强调色；
- 大留白、慢节奏；
- 图片比装饰更重要。

正文：
- 微信正文约 17px；
- 行距约 1.9–1.95；
- 段落上下留白明显，不挤成一整墙字；
- 不人为把每一句拆成一段；
- 加粗只用于真正关键的一两句话，不连续大面积加粗。

二级标题：
- 21px 左右；
- 左侧低饱和豆沙色细线；
- 标题上下有较大留白；
- 不使用 emoji、编号圆点、花哨分隔符。

图片：
- 图片上下留白大于普通段落；
- 图注约 13px、灰棕、居中；
- 图注只说明场景，不显示图库来源、版权核验或抓取方式。

信息卡：
- 暖白底、豆沙色 + 灰棕；
- 去企业蓝、去高饱和色；
- 一篇原则上 0–2 张；
- 只在真正帮助读者理解结构时使用。

结尾：
- 不增加“总结”“写在最后”等机械标题；
- 最后一句自然结束，保留余味；
- 不追加资料来源、图片来源、编辑说明。

## 图片硬门槛

这是发布硬规则：

- 每篇最终微信公众号草稿必须实际包含图片；**0 张图片不得进入草稿箱**。
- 最低 2 张有效图片，通常 3—5 张。
- 优先选择有明确许可的女性生活、友情、家庭、工作、城市和中年生活真实场景；必要时补 1—2 张原创文字卡/关系图。
- 图片必须与文章中的具体情境相呼应；Logo、头像、无关库存图和纯装饰图不计入有效图片。
- 找不到合适外部图时，继续换来源或制作原创信息卡，不得因为找图困难交付无图文章。
- 最终闭环必须确认图片已经实际进入公众号草稿。
