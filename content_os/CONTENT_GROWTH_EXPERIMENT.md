# C/E 公众号阅读增长实验｜2026-10-10 起

## 为什么启动

- 用户反馈：生意显微镜的《泡泡玛特：Labubu之后，最难的一仗才刚开始》明显高于同期其他稿；其他稿一般仅有个位数阅读。没有后台明细，不得推断具体数值和因果。
- 用户反馈：育儿近期各篇通常个位数阅读。先检验题材与标题是否同质、平台是否有推荐曝光，**不直接断定育儿赛道无效**。
- 2026-10-04~09 育儿归档出现连续「孩子…先别/问题可能/父母做错」模式；这属于可以直接修复的重复生产问题。

## 与现有 07:00 / 11:20 任务的关系

07:00 按 Asia/Shanghai 进行7篇当日原创研究及草稿生产；11:20 复核当天7篇是否缺稿、是否存在可修失败，**不是第二轮新文章生产**。两个阶段都先核验当日 archive、SHA256、标题、Gate、Actions 和微信官方草稿回执。已经成功的当天归档不重写，绝不重复调用草稿接口。每号独立执行。

本实验**只影响 C/E 新归档的选题和标题**，其余五号流程、原典、图片与发布边界不变。已经成功的旧归档与成功回执是不可变基线。

## 未来10篇实际发表测试（不是保证流量）

### C 生意显微镜

- 约 6–7 篇大众知名品牌的业务冲突和转折；2–3 篇公司兴衰、价格战和创始人决策；至多1篇与中国读者明确相关的海外企业。
- 每天三个候选：品牌名及认知理由、真实新窗口、官方/可靠来源、冲突矛盾、读者好奇点、近30天去重。没有真窗口不以过时旧闻假装当天热点。
- 对照内部相对强表现的泡泡玛特 Labubu 一文，但不能照抄标题/解释为算法必然偏爱 Labubu。
- 避免把「某国外公司完成收购×亿美元」自动当成公众感兴趣的话题。商业事实未经证实不得写入标题。

### E 育儿

- 重点小学—初中家长，选学校实际处境、家校关系、手机/同伴/青春期冲突、父母分歧；不再机械生成「孩子有问题→父母先别→正确教育」。
- 10篇中约4篇学校教育现实、3–4篇家庭冲突、1–2篇父母处境、约1篇发展/方法，优先选择真实问题，不为了比例虚构案例。
- 标题三个候选必须至少有两个叙事类型：具体场景、身份/立场对立、值得核验的疑问、可执行解决方案。可以有张力，但不得恐吓、贴病名或利用极端未成年人案例。
- `content_os/editorial_guard.py` 自动阻断未来新归档最近6篇重复的模板型标题（仍需要编辑判断主题相似度）；失败只能**修正未成功的新稿**，不可改写已有成功回执的文章。

## 微信选题热度

读 `TOPIC_INTELLIGENCE.md` 和当日 `topic-intelligence/YYYY-MM-DD.json|md`。5个候选+2条独立验证热度不足时记录 `insufficient_evidence` 及已尝试的来源，再使用官方公告、教育机构文件、原始材料继续当天原创，不能断更、不能说微信热度已验证。公共搜索命中不是阅读量。禁止 TinyFish、付费API和验证码绕行。

研究记录（内部，不能混入公众号正文）需写：
`date, profile, 3_title_candidates, selected_title, topic_cluster, event_date, primary_source_urls, article_scan_state, heat_evidence_count, prior_30d_check, editorial_decision, source_limitations`。
不要求为了本报告覆盖已经成功的当日归档。

## 数据记录与决策

**草稿成功 ≠ 正式发表。** 只有微信后台明确显示已发表才纳入阅读实验；记录24/72小时各项数据和提取时点。不公开或未能获取的数据写 `unknown`，不得填0。

建议每篇记录以下字段（按实际可取得项）：

| 字段 | 规则 |
| --- | --- |
| profile / article_date / title | 必须和归档及后台标题匹配 |
| published_at / measured_at | 日期时间和时区必须明确 |
| reads_24h / reads_72h | 已发表文章的真实阅读人数或次数，注明口径 |
| sources / recommended_impressions | 后台有才记；无则 unknown |
| shares / favorites / new_followers | 后台有才记 |
| notes | 是否手动转发、互推、推送位置、平台异常 |

每10篇**已正式发表**文章，比较测试前后已发表文章的阅读中位数（分母、样本量均需列出），同时检查流量来源与分享/收藏情况。样本太小只出方向性结论。

- 商业号若品牌主线产生稳定优于基线的多个样本：继续深化；若只有单篇异常高阅读，不盲目扩题。
- 育儿若新题材仍个位数：先排查关注基数、正式发布状态、来源和推荐曝光；连续两个可比较周期没有改善，再考虑换细分方向或停号。
- 不承诺提升阅读量、开启平台推荐或自动发表。
