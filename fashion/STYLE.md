# 女装穿搭｜Image-first Direction Profile

## 定位

内部 Direction：`fashion`

正式账号名暂不在系统里改写，等待沿用用户现有公众号名称。

核心定位：**明星穿搭 × 日韩穿搭 × 普通人复刻。**

不是时尚资讯搬运号，也不是“看图猜同款”。每篇文章必须先有合格图片和可追溯来源，才允许进入写作。

内容比例建议：
- 45% 明星穿搭：机场、出街、品牌活动、剧宣、日常公开造型；
- 30% 韩国穿搭：通勤、轻熟、机场感、极简、西装、针织、大衣、半裙、直筒裤；
- 25% 日本穿搭：叠穿、材质、层次、低饱和配色、宽松比例、小众风格。

## Image-first 硬流程

固定顺序：

**找图 → 图片权利核验 → 确认人物/品牌/场景 → 单品事实核验 → 穿搭分析 → 普通人复刻 → Quality Gate → Image Gate → 微信草稿**

不得反过来先写文章再随便补图。

没有合格图片时：
- 不生成文章；
- 不拿“相似图片”顶替；
- 不用 AI 图冒充明星、模特或真实街拍；
- 不把 Pinterest / 小红书 / Instagram 的公开可见图片自动视为可转载。

## 图片来源等级

### A级：可直接进入候选池
- 用户自己拥有版权或明确授权的图片；
- Public Domain / CC0；
- 明确允许商业/编辑转载的 CC 或开放许可图片；
- 品牌 Press Kit / Media Kit 明确写明可用于 editorial / press 的素材；
- 联盟/商品 feed 条款明确允许站外内容使用的商品图；
- 获得摄影师、品牌或版权方授权的图片。

### B级：只能作为选题和事实线索，不能自动转载
- 品牌官网普通 Campaign / Lookbook / 商品页；
- 品牌官方微博、Instagram、小红书；
- 明星/艺人官方社交账号；
- 新闻媒体图片页；
- Pinterest。

**“官方发布”不等于“允许转载”。**

如果没有明确许可条款或授权证据，只能用来发现选题、确认造型、核对单品，不能直接进入微信公众号正文。

## 明星穿搭规则

明星穿搭优先选择：
- 品牌官方 press/editorial 素材中明确授权使用的明星活动图；
- 正规图库且已获得可用于公众号编辑用途的授权图；
- 用户提供的合法授权图。

社交媒体公开照片默认不得直接下载再发。

如果当日热门明星造型没有可用图片：
1. 保留为候选；
2. 不出稿；
3. 换下一个有合法图片的题。

## 日韩穿搭规则

优先：
- 有明确开放/编辑使用许可的街拍；
- 品牌 press/lookbook 素材；
- 合法授权的摄影作品；
- 可商用/编辑使用图库中的真实穿搭照片。

Pinterest、小红书、Instagram 可用于发现趋势，但不是默认图片源。

## 单品与“同款”规则

严禁只靠视觉猜品牌、型号、价格。

只有来源能明确证明时才可以写：
- “同款”
- “她穿的是 XXX”
- 精确品牌 / 型号 / SKU / 价格

无法确认时必须改写成：
- “同类版型”
- “类似的短款针织”
- “可以找这种肩线/裤型/配色”
- “这套最值得抄的是比例，不是具体品牌”

## 每篇固定分析维度

不要求机械全部出现，但至少覆盖 5 项：
- 廓形：肩、腰、衣长、裤型、裙摆；
- 比例：上短下长 / 上宽下直 / 内紧外松等；
- 配色：主色、对比度、明度、冷暖；
- 材质：软硬、垂坠、厚薄、光泽；
- 层次：叠穿、露肤、领口、袖口；
- 鞋包：体积、颜色、风格平衡；
- 身材适配：小个子、高个子、肩宽、胯宽等；
- 季节与场景：通勤、约会、旅行、日常；
- 普通人复刻：哪些必须抄，哪些不必抄。

## 普通人复刻

每篇都必须回答：

1. **这套真正值得抄的是什么？**
2. **普通人应该搜什么类型的单品？**
3. **哪些身材需要调整比例？**
4. **预算不够时先把钱花在哪里？**

默认不做“假同款”。

允许写：
- 500 元级搭配思路；
- 1500 元级搭配思路；
- 品类关键词；
- 平替版型逻辑。

涉及具体商品推荐时，商品事实必须从当日可核验页面确认，不凭记忆写价格和库存。

## 标题方向

推荐：
- 《这套机场穿搭真正好看的，不是那只包》
- 《韩国女生穿西装为什么不显“上班感”？关键在这3个比例》
- 《日本女生敢把裙子套裤子，为什么看起来不乱？》
- 《这套大衣看起来贵，真正起作用的是裤子》
- 《160cm照着这套穿，最应该改的不是鞋》
- 《别急着买同款，这套最值得抄的是“上宽下直”》

避免：
- “女明星都在穿”
- “今年不买就过时”
- “显瘦20斤”
- “所有女生都适合”
- 未核验就写“同款”“平替”“某某同款”。

## 文章长度与节奏

正文建议 1400–2400 中文字。

图片为核心证据，通常 3–6 张；
文字围绕图片展开，不写与图无关的长篇时尚史。

推荐结构：
主图 → 第一眼判断 → 廓形/比例 → 配色/材质 → 细节 → 身材适配 → 普通人复刻 → 预算分配。

## 图片与隐私边界

禁止：
- AI 生成明星或真人穿搭图冒充真实照片；
- 偷拍、私密场景、未经许可的普通人照片；
- 儿童/未成年人穿搭作为成人时尚流量素材；
- 水印图库图片；
- 把不同造型的图拼在一起说成同一套；
- 用“相似图片”假装原造型。

## 前台 / 后台分离

后台必须保留：
- 图片 URL；
- 来源页 URL；
- 权利/许可类型；
- 权利证据 URL；
- 是否需要署名；
- 单品来源；
- 图片与正文对应关系。

公开正文不显示技术性核验过程。
如许可要求署名，只显示必要、自然、简短的图片署名，不写内部工作流。

## 发布

归档：`fashion/archive/YYYY-MM-DD.md`

图片核验：`fashion/image_gate.py`

每篇必须包含隐藏的 `FASHION_SOURCE` JSON。

只创建微信公众号草稿，不自动正式发布/群发。
